* auto-watch เปิดได้หลายแท็บพร้อมกัน แต่ละแท็บ mute + ไม่แย่งโฟกัสหน้าจอ
ปิดอยู่ - ไม่มีการสแกน/เก็บ drop ใดๆ
🎉 เก็บครบทุกเกมในลิสต์แล้ว ปิดแท็บที่เปิดไว้ให้แล้ว
⚠️ เครื่อง sleep แล้วการดูจะหยุดชั่วคราว — ตั้งไม่ให้ sleep ตอนนี้
Firefox ไม่มีทางให้ extension กันเครื่อง sleep ได้ (ตรวจสอบแล้ว: ไม่มี power API และ Screen Wake Lock API ก็ใช้กับแท็บ background ไม่ได้ - เจตนา ของ browser เอง ไม่ใช่ข้อจำกัดของ extension นี้) ต้องตั้งที่ Windows เอง:
  1. Settings → System → Power & battery → Screen and sleep
  2. ช่อง "When plugged in, put my device to sleep after" → เลือก Never
หรือใช้คำสั่งนี้ใน PowerShell (สิทธิ์ Admin): powercfg /change standby-timeout-ac 0
อย่าลืมตั้งกลับหลังฟาร์มเสร็จ ถ้าไม่อยากให้เครื่องไม่ sleep ตลอดไป

รายชื่อเกม (เรียงตามลำดับความสำคัญ บรรทัดละ 1 เกม)

แปลงเป็น URL ให้อัตโนมัติ (พิมพ์เล็ก เว้นวรรค→ขีด) หลังบันทึก จะเช็คหน้า All Campaigns ของ Twitch ว่าเกมนั้นมี drop เปิดอยู่จริงไหม แล้วปรับชื่อให้ตรงกับ Twitch ให้เอง เกมที่ไม่มีแคมเปญตอนนี้ auto-watch จะข้ามไว้ก่อน (ตั้งวันเริ่มเองได้ในลิสต์ด้านล่าง)
เปิดใช้ Auto-watch (ไปดูให้เองอัตโนมัติ)
ดูพร้อมกันสูงสุดกี่แท็บ
ลำดับเมื่อเกมเกินโควตาแท็บ
"ใกล้หมดอายุก่อน" ใช้วันหมดแคมเปญจาก Twitch (รู้เกือบทุกเกมที่มี drop เปิดอยู่) เกมที่ยังไม่รู้วันหมดจะเรียงตามลำดับที่ใส่แทนโดยไม่เดา
ยังไม่มีข้อมูลความคืบหน้า (จะขึ้นหลังเปิด auto-watch และหน้า inventory โหลดข้อมูลได้)
ปิดสวิตช์อัตโนมัติเมื่อเก็บ drop ครบทุกเกมแล้ว
พอทุกเกมในลิสต์เก็บครบ/หมดอายุ/ไม่มีแคมเปญแล้ว จะปิดสวิตช์หลักให้เอง (แท็บที่ดูอยู่ปิดเองต่อเกมอยู่แล้วไม่ว่าเปิดอันนี้หรือไม่) ค่าเริ่มต้นปิดไว้
